# S10 | AP5 - Implementacion de formularios moviles

Desarrollo de Aplicaciones Moviles - React Native + Expo (Expo Router, TypeScript)
Alumna: Lizth Yasurqi

Opcion elegida: Registro de Producto.

Campos: Nombre, Precio, Categoria, Stock.

Validaciones:
- Nombre obligatorio.
- Precio mayor a 0.
- Categoria obligatoria.
- Stock entero de 0 o mas.

Se usa useState, TextInput, Pressable, mensajes de error y de exito.
Los datos se guardan solo en memoria. Sin base de datos, APIs ni autenticacion.

## Ejecutar
```
npm install
npx expo start
```
Escanear el QR con Expo Go.
